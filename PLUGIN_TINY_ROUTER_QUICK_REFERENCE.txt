PROJECT GOAL
────────────────────────────────────────────────────────────────────────────
Reduce API costs by 30-40% by classifying low-value messages locally before 
they reach the LLM. Deploy a lightweight DeBERTa classifier as an A0 extension.

WHAT IT DOES
────────────────────────────────────────────────────────────────────────────
Answers 4 questions about every incoming message in <10ms:

  1. Relation to Previous: new | follow_up | correction | confirmation | ...
  2. Actionability:        none | review | act
  3. Retention:            ephemeral | useful | remember
  4. Urgency:              low | medium | high

ROUTING DECISIONS
────────────────────────────────────────────────────────────────────────────
Based on classifications + confidence:

  actionability=none + confidence>0.90 → CANNED (instant, $0)
  relation=correction                 → CORRECTION (clarify)
  urgency=high + actionability=act    → URGENT (priority queue)
  relation=follow_up + history>2      → CONTEXTUAL (tight context)
  confidence<0.55 OR any error        → FALLBACK (full LLM)
  else                                → STANDARD (full LLM)

INTEGRATION POINTS
────────────────────────────────────────────────────────────────────────────
Hook:      message_loop_start (A0 extension point)
Timing:    After LoopData created, before LLM call
Access:    Full history, context, previous action
Action:    Can skip LLM via InterventionException
Fallback:  Standard LLM processing on error/low confidence

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
Model not found:
  → python usr/plugins/tiny-router/download_model.py

ImportError: onnxruntime:
  → pip install -r usr/plugins/tiny-router/requirements.txt

Slow inference (>50ms):
  → Check if CPU overloaded, or try GPU (CUDAExecutionProvider)

Agent crashes after canned response:
  → Ensure InterventionException raised before returning

No classifications in logs:
  → Check if plugin is loaded, enable debug logging

High false positive rate:
  → Lower canned response threshold (0.90 → 0.95), collect more data
